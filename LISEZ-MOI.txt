# CORBÉ 49 — Signature mobile dynamique

Version 1.0.3.0 — fichiers corrigés pour la structure du complément Outlook mobile.

## Fichiers
- `manifest.xml` : manifeste du complément Outlook, événement `OnNewMessageCompose`, runtime HTML `mobile.html`.
- `mobile.html` : charge Office.js, MSAL Browser et explicitement `mobile.js`.
- `mobile.js` : logique de signature CORBÉ 49 et récupération du profil via Microsoft Graph / MSAL NAA.
- `auth.html` : page HTTPS associée à l’inscription SPA.
- `README.md` : résumé du projet.

## Publication GitHub
1. Décompresser l’archive.
2. Dans le dépôt `Xaviouk/corbe49-signature-mobile`, utiliser **Add file > Upload files** et téléverser les six fichiers à la racine, en remplaçant ceux portant le même nom.
3. Commit directement sur `main`.
4. Attendre la publication GitHub Pages puis vérifier `mobile.html` et `manifest.xml`.

## Avant le test Outlook
- Garder l’ancien complément en place tant que la nouvelle version n’a pas été testée.
- L’inscription Entra doit conserver l’URI SPA `brk-multihub://xaviouk.github.io`.
- Microsoft Graph `User.Read` déléguée doit être présente.
- Le code tente l’obtention silencieuse du jeton pendant l’événement de composition. Il ne lance pas de connexion interactive dans cet événement. Si l’authentification silencieuse échoue, la signature utilise les données Outlook disponibles et certains champs Graph, notamment fonction/téléphone, peuvent rester vides.
- Le code et le manifeste doivent encore être testés dans Outlook mobile : l’archive n’est pas une preuve de fonctionnement en production.
