# CORBÉ 49 — Signature mobile (préparation de test)

Cette archive est une version de préparation. Elle n’a pas été déployée ni testée dans Outlook.

## Fichiers
- `mobile.html` : charge Office.js et MSAL Browser.
- `mobile.js` : modèle HTML de signature existant, chargement explicite de MSAL dans le runtime, authentification NAA silencieuse et récupération Graph du profil.
- `auth.html` : page de redirection HTTPS de MSAL.
- `manifest.xml` : manifeste mis à jour, même ID de complément et version 1.0.1.0.

## Avant de déployer
1. Garder le complément actuellement déployé en place comme retour arrière.
2. Publier ces fichiers dans le dépôt `Xaviouk/corbe49-signature-mobile` (ne pas supprimer l'ancien contenu avant sauvegarde).
3. Dans Entra ID > `CORBE49-Signature-Mobile` > Authentification > SPA, conserver `brk-multihub://xaviouk.github.io` et ajouter aussi :
   `https://xaviouk.github.io/corbe49-signature-mobile/auth.html`
4. Confirmer que Microsoft Graph > autorisation déléguée `User.Read` est présente.
5. Valider le manifeste dans le validateur de manifeste Office, puis mettre à jour le complément existant avec ce `manifest.xml`.
6. Tester sur le compte Xavier avant toute diffusion. Si l'acquisition silencieuse du jeton échoue, la signature utilisera le nom et l'adresse e-mail accessibles via Outlook, mais les champs fonction/téléphone resteront vides ; il faudra diagnostiquer l'authentification NAA.

## Comportement des champs
- Fonction : vide si Graph ne renvoie aucune fonction.
- Téléphone : mobile en priorité, puis premier téléphone professionnel ; vide si aucun n'est disponible.
- Photo : URL calculée depuis l'adresse e-mail selon la convention déjà utilisée.
- Le code n'ouvre pas de fenêtre de connexion interactive pendant l'événement de composition.

## Important
Cette version n’a pas été exécutée dans Outlook ni validée contre le tenant. Testez uniquement sur le compte prévu et vérifiez les résultats avant tout déploiement plus large.
