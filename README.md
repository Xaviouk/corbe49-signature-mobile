# CORBÉ 49 — Signature mobile

Complément Outlook mobile permettant d'insérer automatiquement la signature électronique CORBÉ 49.

## Fichiers

- `mobile.html` : page de chargement du complément.
- `mobile.js` : logique d'insertion et de personnalisation de la signature.
- `manifest.xml` : manifeste du complément Outlook, conservé séparément.

## Hébergement

Le complément est hébergé avec GitHub Pages.

## Évolution

La signature est en cours de préparation pour utiliser automatiquement les informations des collaborateurs depuis Microsoft 365.

## Déploiement

Le complément est destiné aux utilisateurs CORBÉ 49. Toute modification doit être testée avant son déploiement général.
